# 🏛️ Месопотамія: Царства (Mesopotamia: Kingdoms)

**Покрокова військово-економічна гранд-стратегія** у стилі класичної гри *Rome: Total War (2004)*, адаптована для навчальної програми з історії стародавнього світу (6 клас).

---

## 🎮 Особливості гри

- 🗺️ **Стратегічна 3D-карта Межиріччя**:
  - Рельєф із горами Загросу, Сирійською пустелею та Перською затокою.
  - Повноводні річки Тигр та Євфрат із мережею зрошувальних каналів.
  - Стародавні торгові шляхи та караванні маршрути.
- 🏙️ **Міста-держави та Споруди у стилі Total War**:
  - 8 автентичних міст: **Урук, Ур, Лагаш, Кіш, Ніппур, Умма, Еріду, Сузи**.
  - 3D-моделі зикуратів, оборонних мурів, прапори та жетони гарнізонів.
  - Будівництво: Зикурати, Канали, Зерносховища, Едуби (школи клинопису), Бронзоливарні майстерні, Храми Інанни.
- ⚔️ **Шумерське військо та Битви**:
  - Ополченці зі списами, Царські важкі фаланги, Колісниці на онаграх, Лучники, Жерці та Каравани.
  - Тактичні штурми ворожих міст, облоги та гарнізонні бої.
- ⏳ **Кампанія на 50 ходів (2600 — 2350 рр. до н.е.)**:
  - Керування ресурсами: Зерно 🌾, Глина 🧱, Бронза 🛡️, Срібло 🪙, Лояльність та Благочестя.
  - Фінальний екран з історичним титулом (*«Лугаль-калем-ма»*, *«Лугаль Кіша»*, *«Енсі»*) та статистикою правління.
- 🧠 **Інтерактивна вікторина для 6 класу**:
  - Питання з історії Стародавнього Дворіччя після кожного ходу з нагородами у ресурсах.
- 📜 **Історичний Кодекс (Енциклопедія)**:
  - Довідник про богів Шумеру (Ану, Енліль, Енкі, Інанна), перші закони, винайдення колеса та клинопису.
- 📱 **Ландшафтний режим (Landscape)** для максимального занурення на смартфонах і планшетах.

## 🚀 GitHub Actions: Автоматична збірка та завантаження APK

У репозиторії налаштовано автоматичний робочий процес **GitHub Actions** (`.github/workflows/build-and-release.yml`), який автоматично збирає інсталяційний `.apk` файл для Android при кожному пуші.

### 📥 Як завантажити готовий APK з GitHub:

1. **Через розділ Actions (Артефакти збірки)**:
   - Перейдіть у вкладку **Actions** у вашому репозиторії на GitHub.
   - Оберіть останній успішний запуск робочого процесу **Build & Release Android APK**.
   - Прокрутіть сторінку донизу до розділу **Artifacts**.
   - Натисніть на **`Mesopotamia-Kingdoms-Strategy-APK`** для завантаження ZIP-архіву з готовим інсталяційним APK файлом.

2. **Через розділ Releases (Офіційні релізи)**:
   - При створенні тегу (наприклад, `v1.0.0`) або при ручному запуску з прапорцем *Create Release* файл `.apk` автоматично публікується у вкладці **Releases** вашого репозиторію для швидкого завантаження.

3. **Ручний запуск збірки (Manual Dispatch)**:
   - Вкладка **Actions** -> **Build & Release Android APK** -> **Run workflow** -> натисніть **Run workflow**.

## 📲 Встановлення на Android

1. Завантажте файл `Mesopotamia-Kingdoms-Strategy-v1.0.apk`.
2. Відкрийте файл на пристрої Android.
3. Дозвольте встановлення з невідомих джерел у налаштуваннях безпеки пристрою.
4. Натисніть **Встановити** та запустіть гру.
